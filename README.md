# TXON Task 01 — Data Cleaning & Basic Visualization

Project internship data science yang berisi proses pembersihan dan analisis dasar dataset Sample Superstore.

## Isi repository

- `TXON_01_Data_Cleaning_Visualization.ipynb` — notebook analisis.
- `Superstore.csv` — dataset yang digunakan.

## Topik analisis

1. Memuat dan menginspeksi data.
2. Menangani missing values dan duplikat.
3. Mengubah kolom tanggal ke tipe datetime.
4. Menghitung statistik dasar.
5. Membuat visualisasi sales, profit, kategori, region, dan segment.

## Menjalankan notebook

Install dependensi berikut:

```bash
pip install pandas matplotlib seaborn jupyter
```

Kemudian buka notebook:

```bash
jupyter notebook TXON_01_Data_Cleaning_Visualization.ipynb
```

Pastikan `Superstore.csv` berada di folder yang sama dengan notebook.
